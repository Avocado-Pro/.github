# 🥑 Avocado Project
**Команда разработчиков и сообщество игровых серверов.**
Мы держим и развиваем игровые серверы, пишем для них плагины и собираем вокруг этого живое коммьюнити.
[![Сайт](https://img.shields.io/badge/сайт-avopro.ru-2ea44f?style=flat-square)](https://avopro.ru)
[![Discord](https://img.shields.io/badge/Discord-@alpacarx%20%40qqneonq-5865F2?style=flat-square&logo=discord&logoColor=white)](#-связь)

## 🎮 Проекты
| Проект | Описание | Стек |
|---|---|---|
| **SCP: Secret Laboratory** | Игровой сервер с кастомными механиками и плагинами | Exiled, C#, .NET |
| **avopro.ru** | Сайт проекта: новости, статус серверов, документация | Next.js, Node.js |
> Сейчас у нас один активный игровой проект — **SCP: Secret Laboratory**. Список расширяется.
## 🛠 Что мы делаем
- 🖥 **Держим серверы** — железо, сеть, обновления, мониторинг и защита от DDoS
- 🧩 **Пишем плагины** — механики, роли, ивенты и админ-инструменты на базе **Exiled (C#)**
- ⚙️ **Автоматизируем** — деплой, конфиги, бэкапы, панель управления
- 📣 **Собираем коммьюнити** — ивенты, обратная связь, тестирование новых механик

## 🤝 Участие
Мы открыты к помощи: плагины, документация, тестирование, дизайн, модерация.
1. Откройте [issue](../../issues) с описанием идеи или найденного бага
2. Сделайте форк и создайте ветку под свою задачу
3. Отправьте pull request — опишите, что изменилось и как это проверить
Перед PR прогоняйте сборку локально и придерживайтесь стиля существующего кода.

**A team of developers and a game server community.** We run and maintain game servers, build plugins for them, and grow a community around them.

**Contact the owners on Discord:** **@alpacarx**, **@qqneonq**
